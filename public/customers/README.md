# Customer Logos

Please add the following logo files to this directory:

1. `hp-logo.svg` - HP logo (white/transparent version)
2. `kaseya-logo.svg` - Kaseya logo (white/transparent version)
3. `microsoft-logo.svg` - Microsoft logo (white/transparent version)
4. `proofpoint-logo.svg` - Proofpoint logo (white/transparent version)
5. `veeam-logo.svg` - Veeam logo (white/transparent version)

## Logo Requirements:
- Format: SVG (preferred) or PNG with transparent background
- Color: White or light version of the logo (will be styled with CSS filters)
- Size: Approximately 140px wide by 60px tall (will be automatically scaled)

## Where to get logos:
You can download official logos from:
- Company websites (usually in press/media kits)
- LogoWine, Seeklogo, or similar logo repositories
- Create SVGs from the images provided

## Alternative:
If you have PNG versions, you can also use those by updating the file paths in:
`/components/modules/customers.tsx`

Change the extension from `.svg` to `.png` for each logo.
